# ДЕНЕГ НЕТ, НО ВЫ ДЕРЖИТЕСЬ

Мобильная игра: смотришь квартиру — угадываешь, сколько стоит ночь. 50 реальных объявлений аренды из Калининграда, три режима, до 1000 очков.

## Запуск

Статичный сайт без сборки — достаточно любого HTTP-сервера:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Публикация на GitHub Pages

1. Создай репозиторий и запушь файлы (`index.html`, `style.css`, `game.js`, `data.js`, `README.md`).
2. Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)`.
3. Через минуту игра будет доступна по `https://<username>.github.io/<repo>/`.

## Режимы

| # | Режим | Механика |
|---|-------|----------|
| 01 | **Угадай прайс** | 10 случайных квартир, ставка бегунком, кнопка «ЗАЧЕКАТЬ» |
| 02 | **Что дороже?** | Выбери более дорогую квартиру из двух |
| 03 | **Влезешь в бюджет?** | Бюджет виден, цены скрыты — выбирай квартиру по фото из трёх |

## Баллы (режим 01)

| Ошибка | Очки |
|--------|------|
| до 5% | 100 |
| до 10% | 80 |
| до 20% | 60 |
| до 35% | 30 |
| больше | 0 |

Максимум — 1000 очков за игру (100 за раунд × 10). В режимах 02 и 03: +100 за верное решение.

## Итоговый статус

- **Эконом на максималках** — стабильно занижал цены (средняя ставка ниже прайса на 5%+)
- **Ценовой экстрасенс** — угадывал точно (в пределах ±5%)
- **Деньги не проблема** — стабильно завышал цены

Плюс итоговый счёт, точность, шеринг (`navigator.share` с фолбэком в буфер обмена) и «ещё раз».

## Технически

- Mobile-first, один экран — один раунд, прогресс 1/10 в шапке
- Прогресс сохраняется в `localStorage` — можно закрыть и продолжить («ПРОДОЛЖИТЬ: РАУНД N/10»), рекорды по режимам тоже хранятся
- Фотографии грузятся лениво, следующая квартира предзагружается; битые фото заменяются заглушкой
- Чистый JS без зависимостей; шрифты — Google Fonts (Unbounded / Inter Tight / IBM Plex Mono)

## Данные

`data.js` — это 50 объявлений, выгруженных из исходного CSV (ссылка, 5 фото, тип, площадь, адрес, рейтинг, отзывы, цена, продавец). Перегенерировать из нового CSV:

```bash
python3 tools/build_data.py "путь/к/файлу.csv"
```
